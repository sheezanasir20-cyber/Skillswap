## 2. Non-Functional Requirements & Security Matrix

| Category | Requirement | Specification | Implementation Strategy | Verification Test | Status |
|---|---|---|---|---|---|
| **Design** | Editorial minimalism, token-based CSS, no decorative gradients, no emojis as UI icons, consistent spacing | `design.md` §1–15 | CSS tokens (`tokens.css`), Lucide icons, Inter typography | CSS token linting, visual snapshot & accessibility review | Planned |
| **Responsive** | Tested at 320px, 375px, 640px, 768px, 1024px, 1440px without horizontal scroll | `design.md` §11 | Mobile-first CSS, fluid containers, collapsible sidebar | Viewport automated tests in Playwright | Planned |
| **A11y** | WCAG 2.2 AA compliant, keyboard navigation, visible focus (`#315F9B`), aria attributes | `ACCESSIBILITY.md`<br>`design.md` §14 | Semantic HTML, Radix/accessible primitives, focus-visible styles | Axe automated a11y tests, keyboard navigation tests | Planned |
| **Auth & Sec** | Argon2/bcrypt password hashing, HttpOnly secure cookies, CSRF protection, rate limiting | `SECURITY.md` §1 | Express bcrypt, express-session/jwt with secure cookies, helmet, cors | Security test suite (`tests/security/auth.security.test.ts`) | Planned |
| **Authz (RBAC)** | Role-based check on every endpoint, strict resource ownership validation | `SECURITY.md` §2<br>`API.md` | Middleware: `requireAuth`, `requireRole`, `requireParticipant` | White-box authorization test suite (`tests/whitebox/authz.matrix.test.ts`) | Planned |
| **Data Integrity** | Foreign keys, unique constraints, transactional state changes | `DATA-MODEL.md` | Prisma ORM migrations, ACID transactions on state changes | Database constraint tests (`tests/integration/db.constraints.test.ts`) | Planned |
| **White-Box Coverage** | 100% critical backend logic, 95% overall backend statement, 90% branch coverage | User Prompt §8 | Vitest + c8 / Istanbul coverage reporting | Coverage report (`TEST-REPORT.md`) | Planned |
| **Performance** | Target 500 concurrent users capability, indexed queries, sub-5s matching | `PRD.md` §9<br>`BACKEND.md` §8 | Indexed PostgreSQL columns, cursor pagination, lightweight payloads | Benchmark and load simulation tests | Planned |
