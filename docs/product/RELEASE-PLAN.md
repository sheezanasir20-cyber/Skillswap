# Delivery Plan

A suggested phased plan. Actual dates and team capacity must be agreed separately.

## Phase 1 — Foundation
- Repository, CI, environments, database migrations.
- Authentication and role model.
- Member profile and skill catalogue.
- Design tokens, responsive shell, public pages.

**Exit:** member can register, sign in, and create a profile with teach/learn skills.

## Phase 2 — Discovery and connection
- Search/filter.
- Match suggestions and explanation.
- Connection request lifecycle.
- Member profile detail.

**Exit:** two members can discover and connect.

## Phase 3 — Communication and sessions
- Conversations and realtime messages.
- Session proposal and confirmation.
- Reschedule/cancel/complete.
- Reminder worker and notifications.

**Exit:** connected members can coordinate a session and receive reminders.

## Phase 4 — Trust and staff tools
- Reviews.
- Reporting.
- Moderation queue and actions.
- Account/role management.
- Activity logs.

**Exit:** complete trust and safety workflow with audit coverage.

## Phase 5 — Analytics and hardening
- Admin analytics.
- Load, security, accessibility, and browser testing.
- Backup restore rehearsal.
- Production monitoring and operational runbooks.

**Exit:** release criteria met and SRS performance target evaluated.

## Scope guard
Do not add payments, video calling, native apps, certificates, or social integrations to this release unless the SRS is formally changed.
